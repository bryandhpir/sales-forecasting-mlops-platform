# Raw dataset

Download the Store Sales - Time Series Forecasting data from Kaggle:
https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data

The data pipeline requires `train.csv` and `stores.csv`.
Additional source files for future analysis include `oil.csv`,
`holidays_events.csv`, and `transactions.csv`.

Source files are excluded from version control by `.gitignore`.
Follow Kaggle competition terms and do not commit downloaded datasets.
